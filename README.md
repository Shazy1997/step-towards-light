# Step Towards the Light

An Islamic motivational and guidance platform that aggregates curated scholarly content and provides community engagement features.

## Features

- Curated scholarly YouTube videos
- Written khutbahs and articles
- Discord community integration
- Events calendar
- Future e-commerce capabilities

## Tech Stack

- Next.js
- Tailwind CSS
- Docker
- Node.js

## Getting Started

### Prerequisites

- Node.js 20 or later
- Docker and Docker Compose
- Git

### Development

1. Clone the repository:
```bash
git clone [repository-url]
cd step-towards-light
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

### Docker Development

Run the application using Docker:

```bash
docker-compose up
```

## Testing

Run the test suite:

```bash
npm test
```
